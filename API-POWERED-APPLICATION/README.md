# EXCHANGE RATE CONVERSION TOOL

Shows current weather for any city using the OpenWeatherMap API.

## Setup

1. Clone the repo
2. Run: pip install requests python-dotenv
3. Create a .env file with: EXCHANGE_RATE_API_KEY=your_key_here
4. Get a free key at app.exchangerate-api.com

## Usage

python day5_project.py
