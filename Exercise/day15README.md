# A Proposal Feedback Tool

An AI assistant that checks, verify, and correct proposal bids in order to help you create a strong and convincing proposal.
You paste your proposal and it checks where you are wrong, which point to add and what to add.

## To Setup

1. pip install anthropic python-dotenv requaest.
2. Create a new file .env with: OPENAI_API=your_api_here.
3. Get your api key from https://platform.openai.com
