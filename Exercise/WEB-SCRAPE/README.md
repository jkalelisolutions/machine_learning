# A Web Scraping Script

A simple script used to scrape/fetch useful data from a website. It can be used in fetching job opportunities, skills required in those jobs, it can also be used by companies to monitor their competitors.

## To Setup

1. pip install csv BeautifulSoup4 requests
2. Check if the website allows scraping by using robots.txt e.g. "https://url/robots.txt"

### To Run

```text
python day22_exercise.py
```
