# Kiambu Poultry Farm

Kiambu Poultry Farm is a lightweight web interface that assist Farmers to get previous egg count, add new egg count and store that data for future reference. This web interface helps in digitizing tasks, prevent loss of data e.g books being worn out or memory loss of the last/previous data. It is simple to use, reliable, and fast.

## To Setup

1. Ensure js file is inside the static file.
2. The html file is inside the templates file.
3. py -m pip install -r requirements.txt

### To Run

```text
python -m flask --app day17_exercise run --debug
```
