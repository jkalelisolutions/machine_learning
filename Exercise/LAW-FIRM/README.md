# A FILE AUTOMATION SCRIPT

An Automation script that organises different formats of files into specified subfolders, producing clean, well organised, and easy to find access different files. It then saves and logs everytime files are moved into their folders. This helps in keeping tabs/history in sections like Finance. This script can be used in; Law Firms, Schools, Corporate offices and anywhere that usually work with files.
