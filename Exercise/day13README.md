# A Matatu Sacco customer service Assistant

The assistant is used to answer basic repetitive questions like "What is my balance?" for a matatu sacco company. This in turn saves time for the secretary to work on other tasks.

## To Setup

1. pip install openai python-dotenv.
2. Create a new file .env with: ANTHROPIC_API=your_api_here
3. Get your api key from https://platform.claude.com

### To Run

python day13_exercise.py
